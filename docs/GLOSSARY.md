# Glossário — myplanner

- **Card**: unidade criada no Trello (título + prioridade + board).
- **Board**: quadro do Trello onde o card é criado.
- **PWA**: Progressive Web App — app web instalável, mobile-first.
- **BFF**: Backend for Frontend — servidor FastAPI que intermedia o PWA e o Trello.
- **Token do Trello**: credencial de acesso à API do Trello; vive somente no servidor.
- **Power-Up**: extensão do Trello usada para gerar a API key (Admin Portal).
- **TOTP**: senha temporária (app autenticador) exigida ao registrar novo aparelho.
- **SemVer**: versionamento semântico `major.minor.patch`.
- **MVP**: versão mínima viável — antes de completo, a versão fica em `0.x.y`.
