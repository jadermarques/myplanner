# ADRs — Architectural Decision Records

Decisões de arquitetura registradas como `NNNN-titulo.md`, com contexto, opções e
trade-offs. Criadas por feature, nunca antecipadas.

Convenção: numeração sequencial `NNNN`, título curto em kebab-case.

Gatilhos que obrigam abrir um ADR antes de especificar (ver `docs/ARCHITECTURE.md`):

- chegada do banco de dados;
- primeira funcionalidade com IA;
- mais de um usuário;
- mais de 3 integrações externas.
